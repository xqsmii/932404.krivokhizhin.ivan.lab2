# Лабораторная работа №2. Базовые и продвинутые возможности CSS

## Цель работы

Научиться подключать стили, работать с селекторами, типографикой, цветами, отступами, позиционированием и псевдоклассами.

## Тема

Вариант №1 «Студент-разработчик» (эффект «карточки навыков» с анимацией масштаба)

## Описание проекта

Страница «О себе» из лабораторной работы №1, оформленная преимущественно с помощью внешнего файла стилей `style.css`. Навыки оформлены сеткой карточек с анимацией масштаба при наведении и нажатии.

## Структура страницы

- `<header>` - шапка с именем студента и заголовком страницы
- `<figure>` с `<img>` - аватар (подключён по внешней ссылке) с атрибутами `src`, `alt`, `width`, `height`
- `<aside>` - боковая панель «Любимые технологии», расположена рядом с аватаром через Flexbox
- `<main>` - основной контент
- `<section>` «Навыки» - сетка карточек-плиток
- `<section>` «Проекты» - нумерованный список
- `<section>` «Обратная связь» - форма с полями «Имя», «Email», «Сообщение» и кнопкой отправки
- `<footer>` - подвал с копирайтом и годом

## Цветовая гамма

Основной цвет - синий (`--color-primary: #1e5aa8`), акцентный - тёмно-синий (`--color-accent: #0b2a5c`). Цвета и шрифты заданы через CSS-переменные в `:root`.

## Реализованные требования

- Основной стиль - во внешнем файле `style.css`
- Inline-стиль: `padding: 20px` у элемента `<header>`
- Внутренний блок `<style>`: стили поля «Email» (увеличенный `padding`, `border-radius`, смена цвета рамки при фокусе)
- CSS-переменные в `:root` для цветов и шрифтов
- Позиционирование:
  - `static` - у `<main>`
  - `relative` - у контейнера сетки карточек `.skills-grid` и у самих карточек
  - `absolute` - у бейджа «Top skill» в правом верхнем углу карточки
- Карточки навыков: при `:hover` плавное увеличение `transform: scale(1.05)` и мягкая тень `box-shadow`, при `:active` уменьшение `transform: scale(0.98)` и более плотная тень
- Состояния ссылок `:link`, `:visited`, `:hover`, `:focus`, `:active`; состояния `:hover`, `:active`, `:focus` у полей формы и кнопки
- Контрастность текста не ниже 4.5:1
